# Closet — バーチャルロッカー＆コーディネーター

「自分のクローゼットを全部知ってるスタイリスト」。手持ちの服を登録すると、気温・行き先・直近の着用履歴から毎朝のコーデを3案提案。買い物では手持ちとの相性をチェックし、着用イメージもAIで生成できる。

## 機能
- **服の登録**：写真をまとめて選ぶだけ。裏で並列処理し、AIが属性（ブランド含む）を解析＋公式オンラインブティック風の商品写真に撮り直して背景を透過、終わったものから自動でクローゼットに登録（NEWバッジ付き、あとから編集）
- **コーデ写真から一括登録**：全身のコーデ写真からアイテムをまとめて検出・切り出し。手持ちと同じアイテムは自動で照合し、着用記録も残せる
- **アイテム編集**：全項目を編集可能。写真の差し替え、AIで再解析、着用写真の切り抜きを白背景の商品写真に整える「商品写真化」
- **今日のコーデ**：天気を自動取得（Open-Meteo）→ 気温と行き先でコードが候補を絞り込み → AIが3案を提案 → 存在しないIDや構成不足をコードで検証し、問題があれば再提案
- **フィードバック学習**：👍👎・「これ着る」・👎の理由を次回の提案に反映
- **買い物の相談**：商品スクショ → 似た服を持っているか、手持ちと何コーデ組めるか、買い/検討/見送り
- **コーデ相談**：自分のコーデ写真 → 手持ちのアイテムを使った改善案
- **試着**：本人の全身写真＋アイテムから着用イメージを生成（着崩しの指示もOK）
- **スタイリストの性格**：バランス / きれいめ紳士 / 攻め / ミニマリスト / 辛口
- **固定アイテム**：ピアス・ブレスなど毎日つける物は全コーデに自動で追加

## 設計方針
- ダミーデータ・モックは使わない。AIが失敗したらエラーを表示する
- 服の写真・履歴はすべて**端末のブラウザ内(IndexedDB)**に保存。サーバー(Pages Functions)はGemini APIの中継だけで何も保存しない
- 設定タブからバックアップの書き出し・読み込みができる

## 構成
- フロント：React + Vite（PWA、スマホのホーム画面に追加可）
- サーバー：Cloudflare Pages Functions（`functions/api/*`）→ Gemini API
- 背景切り抜き：`@imgly/background-removal`（ブラウザ内のWASM）

## Cloudflare Pages へのデプロイ
1. Cloudflare ダッシュボード → Workers & Pages → 作成 → Pages → Gitに接続 → `virtual_closet` を選択
2. ビルド設定
   - フレームワーク: なし
   - ビルドコマンド: `npm run build`
   - ビルド出力ディレクトリ: `dist`
3. 環境変数（設定 → 変数とシークレット）
   - `GEMINI_API_KEY`（シークレット）… 必須
   - `APP_PASSCODE`（シークレット）… 任意。設定すると、アプリの設定タブで合言葉を入れた人だけがAIを使える（公開URLでキーを無断利用されないため）
   - `GEMINI_MODEL` / `GEMINI_IMAGE_MODEL` … 任意。モデルを固定したい時だけ。未設定なら `gemini-flash-latest` などを順に試す
4. 環境変数を追加・変更したら再デプロイする

## ローカル開発
```bash
npm install
echo "GEMINI_API_KEY=xxxx" > .dev.vars
npm run build && npx wrangler pages dev dist   # http://localhost:8788
```
